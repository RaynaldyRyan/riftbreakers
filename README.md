# RIFTBREAKERS — Last Stand of the Void

A top-down arena shooter / bullet hell / roguelite for the make.fun best-game-01 bounty. Fight through a collapsing dimension as a cybernetic combat mech: tear through 10 waves of Void Crawlers, Rift Archers, Iron Brutes, Phantom Drones, Void Stalkers and Rift Guardians, collect energy shards, stack relics (Thunder Core, Phantom Engine, Blood Protocol, Singularity Lens, Overdrive Reactor, Void Piercer), and destroy VORAKH, the Void Sovereign — a 3-phase boss with rotating lasers, homing missiles and dimensional portals.

Controls: WASD move, mouse aim, hold click to fire, Q Nova Blast, E Phase Dash, R Overcharge, SPACE Void Bomb, P pause, M sound, R restart.

## Run it

```sh
python3 -m http.server 8080 --directory game
# then open http://localhost:8080 in desktop Chrome
```
